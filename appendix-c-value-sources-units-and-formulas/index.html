Appendices · Appendix C

Value Sources, Units, and Formulas

In This Chapter

  • Value source kinds (Reader, Derived, Manual, Unknown) and their fields
  • Standard Value Types, symbols, stored units, and reader conversion factors
  • Server-calculated Derived formulas and Check Value Sources status codes

This appendix summarizes the value-level provenance fields, unit conversions, server formulas, and diagnostic status codes used when storing and auditing numeric values in APS ELN (Chapter 9 and Chapter 16).

Value source kinds and provenance fields

Every numeric value stored on a Procedure (Proc) or Action (Action) carries a record type (EXP_CONDITION for inputs or TEST_RESULT for outputs) and one of four source_kind values (Table C-1).

Table C-1: Value source kinds and their stored provenance fields.

Source kindHow it is createdRequired and optional provenance fields
ReaderExtract Values in the GUI, or extract_file_key_values + add_value / add_values in MCPRequires source_file_id (must belong to the item, an ancestor, or a descendant in the same project), reader_id, key_name, reader_units, and finite non-zero conversion_factor; optional reader_version and analysis_snapshot (JSON with matching file_id and file_hash).
DerivedRight-click item > Add > Derived Value..., or add_derived_value in MCPCreated by the server from formula_id, formula_version, and inputs (role -> stored value_id or value_id[]). Client-supplied result numbers are refused.
ManualItem > Add Value in the GUI, add_value in MCP without reader_id, or hand-editing a Reader/Derived valueOptional source_file_id and source_note (up to 1,000 characters, such as a script or job identifier). Reader and conversion fields are refused on Manual values.
UnknownLegacy records created before format 5 source trackingNo source fields; cannot be re-evaluated from files by check_value_drift.

Derived value formulas

Choosing Add > Derived Value… in the Desktop GUI or calling add_derived_value through MCP evaluates a versioned server formula (Table C-3).

Table C-3: Built-in Derived value formula specification.

Formula ID & VersionEquationInput roles and required unitsOutput Value Type and unit
wear_rate_reciprocating (version 1)K = A / (2 · Fn · N)area: Wear area in mm2 (accepts one value ID or an array of value IDs, using their arithmetic mean; A ≥ 0); normal_force: Normal force in N (Fn > 0); cycles: Cycles without unit (N > 0). Plausible-range and drift diagnostic codes

Table C-4 lists the diagnostic codes returned by value entry validation (add_value, add_values, report_value_issues), storage verification (check_storage), and provenance drift auditing (Check Value Sources… / check_value_drift).

Table C-4: Validation, storage, and drift status codes.

Tool / CheckCodeCondition that triggers the code
add_value / report_value_issuesbelow_range, above_rangeThe stored value is below range_min or above range_max of its Value Type.
add_value / report_value_issuestolerance_exceeds_valueA non-zero tolerance is strictly larger than |value|.
add_value / report_value_issuestolerance_scale_mismatchA non-zero tolerance is smaller than |value| / tolerance_factor (default 1000).
check_storage / download_fileok, missing, content_mismatch, no_hash, errorAttachment bytes match stored MD5 (ok), file is absent from storage (missing), bytes on disk differ from stored MD5 (content_mismatch), legacy file record has no hash (no_hash), or I/O error (error).
check_value_drift (Reader)value_changed, reader_version_changed, reader_changed, reader_units_changedRe-running the current reader on the stored file produces a different number, uses a newer reader version or different reader plugin, or emits a different unit.
check_value_drift (Reader)key_missing, file_missing, read_failedThe source key is no longer emitted, the source file is missing, or the reader could not parse the file.
check_value_drift (Snapshot)source_changed, selection_changed, interval_unusableThe file hash differs from analysis_snapshot, the shared .fibps regions or .zrw interval changed after extraction, or the stored interval has fewer than 2 samples in the file.
check_value_drift (Derived)input_changed, input_missing, formula_version_changed, formula_version_mismatch, dependency_cycle, not_fully_rerunnableAn input value drifted or was deleted, a newer formula version exists, the saved formula version is unavailable, a cycle exists in inputs, or an input in the chain is Manual / Unknown.
