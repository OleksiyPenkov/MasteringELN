This appendix summarizes the value-level provenance fields, unit conversions, server formulas, and diagnostic status codes used when storing and auditing numeric values in APS ELN (<a href={`${import.meta.env.BASE_URL}/ch9-values-units-formulas-and-provenance#conditions-results-units-and-plausible-range-checks`}>Chapter 9</a> and <a href={`${import.meta.env.BASE_URL}/ch16-reading-data-and-auditing-drift-via-mcp#running-the-three-project-wide-health-checks`}>Chapter 16</a>).

## Value source kinds and provenance fields

Every numeric value stored on a **Procedure** (`Proc`) or **Action** (`Action`) carries a record type (`EXP_CONDITION` for inputs or `TEST_RESULT` for outputs) and one of four `source_kind` values (<a href="#table-c-1">Table C-1</a>).

<p id="table-c-1" class="table-caption"><strong>Table C-1:</strong> Value source kinds and their stored provenance fields.</p>

<DataTable
  headers={['Source kind', 'How it is created', 'Required and optional provenance fields']}
  rows={[
    ['`Reader`', '**Extract Values** in the GUI, or `extract_file_key_values` + `add_value` / `add_values` in MCP', 'Requires `source_file_id` (must belong to the item, an ancestor, or a descendant in the same project), `reader_id`, `key_name`, `reader_units`, and finite non-zero `conversion_factor`; optional `reader_version` and `analysis_snapshot` (JSON with matching `file_id` and `file_hash`).'],
    ['`Derived`', 'Right-click item > **Add > Derived Value...**, or `add_derived_value` in MCP', 'Created by the server from `formula_id`, `formula_version`, and `inputs` (role -> stored `value_id` or `value_id[]`). Client-supplied result numbers are refused.'],
    ['`Manual`', '**Item > Add Value** in the GUI, `add_value` in MCP without `reader_id`, or hand-editing a `Reader`/`Derived` value', 'Optional `source_file_id` and `source_note` (up to 1,000 characters, such as a script or job identifier). Reader and conversion fields are refused on `Manual` values.'],
    ['`Unknown`', 'Legacy records created before format 5 source tracking', 'No source fields; cannot be re-evaluated from files by `check_value_drift`.'],
  ]}
/>

## Plausible-range and drift diagnostic codes

<a href="#table-c-4">Table C-4</a> lists the diagnostic codes returned by value entry validation (`add_value`, `add_values`, `report_value_issues`), storage verification (`check_storage`), and provenance drift auditing (**Check Value Sources...** / `check_value_drift`).

<p id="table-c-4" class="table-caption"><strong>Table C-4:</strong> Validation, storage, and drift status codes.</p>

<DataTable
  headers={['Tool / Check', 'Code', 'Condition that triggers the code']}
  rows={[
    ['`add_value` / `report_value_issues`', '`below_range`, `above_range`', 'The stored value is below `range_min` or above `range_max` of its Value Type.'],
    ['`add_value` / `report_value_issues`', '`tolerance_exceeds_value`', 'A non-zero tolerance is strictly larger than $|\\text{value}|$.'],
    ['`add_value` / `report_value_issues`', '`tolerance_scale_mismatch`', 'A non-zero tolerance is smaller than $|\\text{value}| / \\text{tolerance\\_factor}$ (default $1000$).'],
    ['`check_storage` / `download_file`', '`ok`, `missing`, `content_mismatch`, `no_hash`, `error`', 'Attachment bytes match stored MD5 (`ok`), file is absent from storage (`missing`), bytes on disk differ from stored MD5 (`content_mismatch`), legacy file record has no hash (`no_hash`), or I/O error (`error`).'],
    ['`check_value_drift` (`Reader`)', '`value_changed`, `reader_version_changed`, `reader_changed`, `reader_units_changed`', 'Re-running the current reader on the stored file produces a different number, uses a newer reader version or different reader plugin, or emits a different unit.'],

    ['`check_value_drift` (`Derived`)', '`input_changed`, `input_missing`, `formula_version_changed`, `formula_version_mismatch`, `dependency_cycle`, `not_fully_rerunnable`', 'An input value drifted or was deleted, a newer formula version exists, the saved formula version is unavailable, a cycle exists in inputs, or an input in the chain is `Manual` / `Unknown`.'],
