Part 1 · Chapter 4

Your First Sample Record in Twenty Minutes

In This Chapter

  • Building the complete Study A (261015A) item tree before attaching files
  • Naming raw measurement files so sample codes stay consistent and results stay out of filenames
  • Attaching deposition, step-height, nanoindentation, and tribometry files in one pass
  • Extracting Reader values and calculating the reciprocating wear rate as a Derived value

The fastest way to learn APS ELN is to record one real sample from start to finish. In this chapter, you’ll build Study A (261015A), a boron nitride and diamond-like carbon (BN/DLC) coating grown by magnetron sputtering and tested on three instruments. All 11 raw files are in the book’s demonstration bundle (/MasteringELN/data/study-a/). When you finish, your notebook will contain 6 items, 11 raw files with verified MD5 hashes, 23 Reader values, and 1 Derived wear-rate value (Figure 4-1).

Meet Study A: sample 261015A

You deposit a BN/DLC coating (261015A) onto silicon and masked steel substrates in a magnetron sputtering system, and then run four characterization steps:

  1. Deposition (Deposition 261015A): the sputtering system writes a summary file (Deposition_BN-DLC_(261015A)_2026-10-15_17-21-48.depo.json), a run metadata file (2026-10-15_17-21-48_BN-DLC(DLCTOP).run.json), and a time-series log (2026-10-15_17-21-48_BN-DLC(DLCTOP).tsv).
  2. Coating thickness (Thickness 261015A): a Filmetrics Profilm3D optical profiler scans across the masked step edge on the steel piece at three positions (1.fibps, 2.fibps, 3.fibps).
  3. Hardness and modulus (Indentation 261015A): an Anton Paar UNHT nanoindenter runs a 9-indent series on the coating (BN-DLC(261015A).mit).
  4. Friction and wear (Friction test 261015A and Wear track 261015A): a DaVinci 1000 tribometer runs a 1,000-cycle reciprocating test at 1 kgf1\,\text{kgf}1kgf (Fn=9.81 NF_n = 9.81\,\text{N}Fn​=9.81N) (BN-DLC.zrw). Next, the optical profiler measures the cross-sectional area of the wear track at three positions (wear 1.fibps, wear 2.fibps, wear 3.fibps).

Step 1: Build the whole item tree first

Always build the entire item tree before you start attaching files (Chapter 1: Four rules that keep your data trail unbroken). That way, every planned measurement has a home in the tree, and you can see immediately if any step is still missing its files.

  1. Download and unpack Study-A-261015A-raw.zip from /MasteringELN/data/. Open your notebook (Chapter 2). In the Projects panel on the left, choose Project > New Group and enter the group name Practice. Next, right-click your Practice group and choose New Project… to create and select Study A Practice (Chapter 5).
  2. Choose Item > New Procedure. Set Title to Deposition 261015A, select the item type Synthesis and Action type Deposition, and click Save.
  3. Select Deposition 261015A in the Items panel and choose Item > New Specimen. Set Title to 261015A, describe the substrates in Description, and click Save.
  4. Select specimen 261015A and choose Item > New Action three times to create its three child actions:
    • Thickness 261015A (Action type: 3D Profiling)
    • Indentation 261015A (Action type: Indentation)
    • Friction test 261015A (Action type: Tribotest)
  5. Select Friction test 261015A (not the specimen!) and choose Item > New Action to create its child action Wear track 261015A (Action type: 3D Profiling).

In ELN

If your laboratory equipment is not yet listed in the Equipment drop-down, select an Item type and Action type first. Then click the + button beside Equipment (tooltip: Add new equipment) and fill in Model, Manufacturer, and Location; all three fields are required to enable OK.

Step 2: Attach the 11 raw files to their actions

Now attach the raw files from /MasteringELN/data/study-a/ to the five procedure and action items in Table 4-1:

  1. Select Deposition 261015A in the item tree and choose Item > Add File (or click Add File on the toolbar).
  2. In the file browser, select Deposition_BN-DLC_(261015A)_2026-10-15_17-21-48.depo.json, 2026-10-15_17-21-48_BN-DLC(DLCTOP).run.json, and 2026-10-15_17-21-48_BN-DLC(DLCTOP).tsv.
  3. Because multiple files are selected, click Review files to open Files to attach. Verify that the .depo.json file uses the Deposition file type (not plain JSON), keep Keep display names selected, and click Attach.
  4. Select Thickness 261015A, choose Item > Add File, select 1.fibps, 2.fibps, and 3.fibps, and attach them.
  5. Select Indentation 261015A, choose Item > Add File, select BN-DLC(261015A).mit, and click Attach. For a single file, ELN attaches it directly from the file browser without a second dialog.
  6. Select Friction test 261015A and attach BN-DLC.zrw.
  7. Select Wear track 261015A and attach wear 1.fibps, wear 2.fibps, and wear 3.fibps.

Remember

Never put measurement results into file names. Name files after the sample code and position (1.fibps, wear 1.fibps, BN-DLC(261015A).mit). Adding a file copies its bytes into notebook storage and records its MD5 checksum; your original file in the source folder is never moved or altered.

Step 3: Extract Reader values from the files

With all 11 files attached, extract their numbers so every stored value carries a Reader source (Figure 4-1):

  1. Deposition parameters and logs (Deposition 261015A): Click the .depo.json attachment to preview it in the Deposition viewer, then click Extract Values. Select the 10 condition keys (Parameters.CleaningTime =60 s= 60\,\text{s}=60s, Parameters.P =0.267 Pa= 0.267\,\text{Pa}=0.267Pa, Parameters.PowerBN =134 W= 134\,\text{W}=134W, Parameters.TimeBN =50 s= 50\,\text{s}=50s, Parameters.Bias =8 V= 8\,\text{V}=8V, Parameters.Warmuptime =500 s= 500\,\text{s}=500s, Parameters.N =46= 46=46, Parameters.CurrentC =0.312 A= 0.312\,\text{A}=0.312A, Parameters.TimeC =190 s= 190\,\text{s}=190s, Parameters.TimeCtop =340 s= 340\,\text{s}=340s). Also select the 2 result keys (Duration =12941.5 s= 12941.5\,\text{s}=12941.5s, BasePressure =9.10×10−5 Pa= 9.10 \times 10^{-5}\,\text{Pa}=9.10×10−5Pa). Keep Remember choices for this reader ticked and click OK.
  2. Coating step height (Thickness 261015A): In the FIBPS viewer, verify the step evaluation regions on 1.fibps and 2.fibps (and automatic step detection on 3.fibps). Select all three .fibps files in the item tree (Ctrl+click), right-click, and choose Extract values from 3 files…. Map Step Height to the thickness/step-height value type (m). ELN writes one Reader value per file (3.58×10−7 m3.58 \times 10^{-7}\,\text{m}3.58×10−7m, 3.16×10−7 m3.16 \times 10^{-7}\,\text{m}3.16×10−7m, and 3.55×10−7 m3.55 \times 10^{-7}\,\text{m}3.55×10−7m), storing each Step Height STD as the tolerance.
  3. Hardness and modulus (Indentation 261015A): Click BN-DLC(261015A).mit to view the 9 loading-unloading curves in the MIT viewer, then click Extract Values (Figure 4-2). Store Hardness (5.92±0.47 GPa5.92 \pm 0.47\,\text{GPa}5.92±0.47GPa) and Modulus (127.17±11.06 GPa127.17 \pm 11.06\,\text{GPa}127.17±11.06GPa). The reader pairs Hardness STD and Modulus STD into the Tolerance field automatically.
  4. Friction test (Friction test 261015A): Click BN-DLC.zrw in the ZRW viewer and check the plateau evaluation interval. Click Extract Values to store the conditions Fn (9.81 N9.81\,\text{N}9.81N) and Cycles (100010001000) and the result COF (0.528±0.0190.528 \pm 0.0190.528±0.019).
  5. Wear track cross-sectional area (Wear track 261015A): Select wear 1.fibps, wear 2.fibps, and wear 3.fibps in the item tree, right-click, and choose Extract values from 3 files…. Store the three Wear Area values (0.00620 mm20.00620\,\text{mm}^20.00620mm2, 0.00553 mm20.00553\,\text{mm}^20.00553mm2, and 0.00621 mm20.00621\,\text{mm}^20.00621mm2).

Tip

If you extract values from the same file a second time, APS ELN updates the existing Reader value that came from that file instead of creating a duplicate row. Your (n=3) count on Thickness 261015A stays at 3.

Step 4: Compute the Derived wear rate

Finally, compute the reciprocating wear rate KKK from the stored wear-track areas, normal load, and cycle count without using an external calculator or spreadsheet:

  1. Right-click Friction test 261015A in the item tree and choose Add > Derived Value….
  2. In the Formula drop-down, select the reciprocating wear rate formula (wear_rate_reciprocating, version 1):
K=A2⋅Fn⋅NK = \frac{A}{2 \cdot F_n \cdot N}K=2⋅Fn​⋅NA​
  1. For the area input role, Ctrl+click all three stored Wear Area values (0.00620 mm20.00620\,\text{mm}^20.00620mm2, 0.00553 mm20.00553\,\text{mm}^20.00553mm2, and 0.00621 mm20.00621\,\text{mm}^20.00621mm2) from child action Wear track 261015A. The dialog automatically takes their mean (A=0.00598 mm2A = 0.00598\,\text{mm}^2A=0.00598mm2) and records all three value IDs as inputs.
  2. For normal_force, select Fn (9.81 N9.81\,\text{N}9.81N). For cycles, select Cycles (100010001000).
  3. Check the previewed result (K=3.05×10−7 mm3/(N⋅mm)K = 3.05 \times 10^{-7}\,\text{mm}^3/(\text{N}\cdot\text{mm})K=3.05×10−7mm3/(N⋅mm)) and click Save.
  4. Right-click the root procedure Deposition 261015A and choose Check Value Sources…. APS ELN re-reads all 11 source files through their current viewer plugins and re-evaluates the Derived wear rate from its stored inputs. It then reports all 24 values unchanged (Figure 4-1).
Going Deeper: what Check Value Sources verifies on a Derived value

When you run Check Value Sources… on an item tree (or call check_value_drift through MCP), APS ELN checks both levels of provenance:

  • For every Reader value, it runs the current reader plugin on the stored attachment bytes and applies the saved unit conversion factor. It also applies any saved analysis snapshot, such as ticked indents or a ZRW cycle interval, and compares the output with the stored number.
  • For every Derived value, it re-reads the Reader inputs from their files and computes their mean when multiple inputs fill one role (such as the three Wear Area scans). It then runs the saved formula version (wear_rate_reciprocating version 1). If an input value was edited or deleted after the Derived value was created, the check flags input_changed or input_missing.
