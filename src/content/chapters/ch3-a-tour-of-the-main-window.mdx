Once you open a local notebook or sign into your laboratory server (<a href={`${import.meta.env.BASE_URL}/ch2-opening-a-notebook#two-ways-eln-stores-your-laboratory-work`}>Chapter 2: Two ways ELN stores your laboratory work</a>), APS ELN opens its main window. Almost everything you do in the program follows one left-to-right flow across three resizable panels (<a href="#fig-3-1">Figure 3-1</a>).

## The three-panel workspace

The main window is divided into four areas (<a href="#fig-3-1">Figure 3-1</a>):

1. **The Projects panel (left):** shows your active projects, project groups, and specimen folders as a tree. Clicking a project or folder loads its scientific records into the center panel.
2. **The Items panel (center):** shows the scientific hierarchy inside the selected project or folder: **Procedures** (`Proc`), **Specimens** (`Item`), and **Actions** (`Action`), along with the files, rich-text notes, and protocol forms attached to each record.
3. **The Content Viewer (right):** displays the live preview of whichever file, protocol, value list, or hypothesis you select in the center panel, using the 26 built-in viewer plugins (<a href={`${import.meta.env.BASE_URL}/ch7-raw-files-drafts-and-instrument-viewers#inside-the-five-core-instrument-viewers`}>Chapter 7: Inside the five core instrument viewers</a>).
4. **The Status bar (bottom):** displays the active connection mode (**Local** or **Remote**), the open `.sqlite` database path or server address, the selected attachment, and the build version number.

You can drag the vertical splitter bars between the three panels to give more width to the item tree or to a wide chart in the Content Viewer.

<InELN>The main menu bar across the top of the window groups every command under seven headings: **File**, **Project**, **Item**, **Navigate**, **Reference Data**, **Tools**, and **Help**. Before a notebook is open, commands that require an active notebook remain disabled.</InELN>

When an action holds repeated values of the same value type, record type, and description (such as the three step-height scans on `Thickness 261015A`), the item tree summarizes them automatically on one line as the mean, the sample standard deviation, and the count: for example, `d = 343.0 ± 23.5 nm (n=3)`. Opening the action dialog with **Item > Edit** still lists each individual value row and its source file.

When you select a **Procedure**, **Specimen**, or **Action** row that has child rows, three small buttons appear at the right end of that row:

- **Collapse all below:** closes every nested level under the selected row.
- **Expand all below:** opens every nested level under the selected row.
- **Focus** (tooltip: **Focus: collapse everything else**): collapses all other branches in the tree while keeping the path to your selected row open and scrolled into view.

<Tip>When a project has dozens of depositions, click a procedure row and click **Focus** on its right edge. Every other procedure folds away so you can work on your current sample without scrolling.</Tip>

<Warning title="dragging items in the tree">Dragging one procedure, specimen, or action row onto another row in the item tree can make the dragged record a child of the target row rather than reordering siblings. To change the manual order of a top-level root procedure safely, select the root item and press `Ctrl+Up` or `Ctrl+Down` (or use **Move Up** and **Move Down**). To move an item to another parent or folder, right-click it and choose **Move to...**.</Warning>

## The Dashboard and keyboard navigation

Each panel has a search bar at the top that filters the rows shown in that panel. When a panel filter is active, clear its search box to see all rows again. For a notebook-wide search or an overview of recent work, use the **Navigate** menu and the **Dashboard**.

<InELN>In **APS ELN Community**, press `Ctrl+D` (or choose **Navigate > Dashboard**) to open the notebook overview, press `Ctrl+F` (or choose **Navigate > Search...**) to search across all notebook records, press `Ctrl+G` (or choose **Navigate > Go to Item...**) to jump to an item by ID, and press `F1` for **Help > Keyboard Shortcuts...**.</InELN>

<InTeamLab title="the Team Lab Dashboard and Ctrl+D">

In the Commercial ("For Teams") edition, open the Dashboard from **Edit > Dashboard**. On a shared laboratory server, the Dashboard displays five live cards:

- **Recent Items:** your most recently modified records across all projects.
- **Protocols Awaiting Review:** protocol forms submitted by students that need supervisor sign-off.
- **Waiting for You:** hypotheses waiting on a human gate (**Approve proposal** or **Accept conclusion**), showing the project, author, and waiting time.
- **Project Statistics:** item counts across your active projects.
- **Activity Feed:** recent changes across your group (supervisors with **Super** or **Admin** roles can filter by student account and time range).

Double-click any entry on the Dashboard to jump straight to that project and item. Note that in the Commercial client, pressing `Ctrl+D` while the **Items** panel has focus duplicates the selected item (**Item > Duplicate**).

</InTeamLab>

## Setting preferences and plugin paths

You can adjust how the main window looks and where it loads templates and plugins by opening **Tools > Preferences...**:

- **General settings:** switch the VCL visual theme (light or dark), configure the startup Dashboard, set default chart appearance, control preview scope, and toggle whether numeric item IDs are shown beside titles in the tree.
- **Tree settings:** adjust font scale, row spacing, hierarchy tint, and level colors so long item trees are comfortable to read on your monitor.
- **Path settings:** choose the folders for protocol/experiment templates, viewer plugins (`Plugins`), and your laboratory report logo. Any change to the plugin directory takes effect the next time you start the program.

<Remember>The attachment storage root displayed in **Tools > Preferences...** is shown for information only. Changing preferences does not move your stored attachment files. To move a local Community notebook, close the program and move the folder containing both the `.sqlite` file and its attachment directory (<a href={`${import.meta.env.BASE_URL}/ch2-opening-a-notebook#how-to-back-up-a-local-notebook-safely`}>Chapter 2: How to back up a local notebook safely</a>).</Remember>
