Part 2 · Chapter 7

Raw Files, Drafts, and Instrument Viewers

In This Chapter

  • Attaching single and multiple files and understanding compound extensions
  • Inspecting data in the specialist viewers: Deposition, FIBPS, MIT, ZRW, and X-Ray Calc
  • Saving and reloading working drafts when editing attachments in external programs
  • Using the Markdown Editor and the standalone ELN File Viewer

Every measurement starts with a raw file (Chapter 1: Four rules that keep your data trail unbroken). When you attach a file in APS ELN, the program records its MD5 checksum, builds a preview thumbnail, and opens it in one of 26 built-in Content Viewer plugins. In the specialist viewers, you can also mark step-height regions, tick valid indents, or set a friction cycle window. APS ELN saves those selections with the file so your extracted values stay reproducible (Chapter 9).

How file attachment and extension routing work

To attach one or more files to a Procedure, Specimen, or Action, select the item in the Items panel and choose Item > Add File (or click Add File):

  • Attaching one file: Select the file in the built-in file browser, check Attachment file type and Display name, and click Attach. There is no second confirmation dialog.
  • Attaching multiple files: Select several files in the browser and click Review files to open Files to attach. There you can inspect each row’s Source filename, Display name, and Type, and either keep Keep display names selected or choose Use prefix: to number a series of scans automatically.

Remember

APS ELN routes files by their longest matching extension. A .depo.json snapshot opens in the specialist Deposition viewer rather than the plain JSON viewer. Similarly, a .process.log file opens in the Process Log viewer rather than the sputtering .log viewer. When suggested display names are created, ELN strips the full compound suffix (.depo.json or .process.log) instead of stripping only .json or .log.

When you select a .depo.json file in the file browser, APS ELN can automatically expand your selection to include its paired .tsv time-series log file. It then opens the Files to attach review dialog so both files are attached to the procedure together.

Inside the five core instrument viewers

APS ELN ships with 26 viewer plugins (NOTATION.md, Section 5). General-purpose viewers handle .pdf, .html, .md (Markdown), images (.png, .jpg, .bmp, .tif), columnar text (.dat, .csv, .txt, .ascii), and .json. Other viewers handle Office documents (.xlsx, .docx, .pptx via OLE), OriginLab projects (.opju), Gatan TEM images (.dm3), and LAMMPS simulations (.lmpin, .dump, .data).

Five specialist viewers handle the files in Study A (261015A) and Study B (261014B) (Table 7-1):

  1. Deposition (.depo.json, .tsv), Recipe (.rcpx), and DSC (.dsc):
    • Attaching both the .depo.json snapshot and its paired .tsv log to the same Procedure unlocks the Overview, Recipe, Pressure, Temperature, Gas Flow, Bias, V / I, and Stage tabs. If the .tsv file is missing from the item, the viewer warns Not attached to this item - charts unavailable.
    • Extract Values reads the .depo.json file (aps.deposition) to give recipe conditions such as pressure, power, current, gas flow, layer times, and period count NNN. It also extracts the run results Duration and BasePressure (Figure 7-2).
  2. FIBPS 3D optical profilometer (.fibps, reader aps.fibps):
    • Displays the surface height map in micrometers (μm\mu\text{m}μm, or nm\text{nm}nm below 1 μm1\,\mu\text{m}1μm) with six interactive tools: Profile, Distance, Roughness (RaR_aRa​, RqR_qRq​, RzR_zRz​ inside a dragged rectangle), Flatten, Step Height, and Wear Track. In Profile, click for a horizontal line profile or Shift+click for a vertical profile.
    • In Step Height, two rectangles (A and B) mark the coated and uncoated levels. Dragging them updates the step h±sh \pm sh±s and saves those rectangles as the shared regions of the file in the notebook.
    • In Wear Track, the viewer automatically detects the wear groove and levels the outer surface to zero (Figure 7-3). It then integrates the cross-sectional area of each row between the groove edges to give Wear Area (mean ±\pm± SD along the track).
    • Clicking Copy Data copies the active profile to the clipboard in OriginLab’s three-header-row layout (Long Name, Units, Comments).
  3. MIT nanoindentation (.mit, reader aps.mit):
    • Plots the contact-zeroed load-displacement curves (subtracting frame compliance when stored) and lists every indent under Records:.
    • Use All, None, or individual checkboxes to tick the valid indents, and click Average or Instrument fit to overlay the mean curve or the unloading power-law fit (Figure 7-4). The ticked indents are saved as the file’s shared selection and recorded in the provenance snapshot of the extracted Hardness (HITH_{\text{IT}}HIT​), Modulus (EITE_{\text{IT}}EIT​), and Reduced Modulus (ErE_rEr​) values.
  4. ZRW tribometer (.zrw, .zrv, reader aps.zrw):
    • Reads both classic Data.dat archives and logger packages (force.raw, resistance.tsv, test.json) and plots friction coefficient (COF) against cycles.
    • In the Interval bar, choose Automatic (first stable plateau covering at least 20% of cycles) or Manual (From / To cycles). Click Apply to save the shared interval (Figure 7-5). Extract Values uses the applied interval to compute COF and its tolerance (COF STD).
  5. X-Ray Calc (.xrcx, reader aps.xrcx) and XRDML (.xrdml):
    • The XRDML viewer plots raw X-ray diffraction and reflectivity scans.
    • The X-Ray Calc viewer opens .xrcx project archives and plots the measured and calculated reflectivity curves on a log axis. Beside the plot, it shows the Structure table (HHH, σ\sigmaσ, and ρ\rhoρ of each layer; Figure 7-6). Extract Values reads the main periodic stack’s mean Period, layer thicknesses, and Chi2.

Warning: always click Apply in the ZRW viewer after changing the cycle interval

In the ZRW viewer, typing new From and To cycle numbers previews the mean COF in the status line, but Extract Values never reads an unapplied draft. Click Apply first so your interval is saved as the shared selection of the file. If a file is later replaced via Reupload…, its old interval is marked stale until you click Apply again.

Working drafts, external edits, and conflict resolution

When you double-click an attachment (or click Open in the viewer toolbar), it opens in an external Windows program such as OriginLab, Excel, or X-Ray Calc 3. APS ELN never lets the external program edit the file inside your notebook storage folder directly. Instead, it writes a separate local working copy (Figure 7-1).

To save changes from an external program back into your notebook:

  1. Save the file inside the external application (which updates the local working copy), and close the external editor window if required.
  2. Select the attachment in APS ELN and choose Tools > Save Attachment Working Draft to copy the updated bytes into notebook storage and update the attachment’s MD5 hash.
  3. If you want to discard your external edits and revert to the bytes stored in the notebook, choose Tools > Reload Attachment Working Draft and confirm the discard prompt.

If you close the notebook or exit APS ELN while a working draft has unsaved changes, the program prompts you before closing. Clicking Cancel stops the close, while clicking No leaves your draft file at the temporary path shown in the message so you do not lose your work.

For .md attachments and project Wiki pages (Chapter 13: The five-section Project Wiki), clicking Edit in the Markdown viewer opens the built-in Markdown Editor. Press Ctrl+S to save, Ctrl+B for bold, Ctrl+I for italic, Ctrl+K for links, and Ctrl+V to paste clipboard images directly as uploaded attachments. If the stored attachment was updated by another session or by an MCP agent while you were editing, the conflict dialog offers three explicit choices:

  • Cancel: keep your editor text open without overwriting the stored attachment.
  • Reload (discard my edits): replace your editor text with the current stored attachment.
  • Save Anyway (overwrite server): overwrite the stored attachment with your draft (if write permissions and signature guards allow it).

Replacing, moving, exporting, and viewing files outside a notebook

Right-click any attached file in the Items panel to replace, rename, move, or export it without breaking its links:

  • Reupload…: replaces the stored bytes of the attachment with a new file from disk (keeping the same file_id and preserving compound file types such as .depo.json).
  • Edit: renames the attachment’s display title or updates its description.
  • Move to…: moves the attachment to another writable, unsigned item in the project.
  • Export: copies the stored attachment bytes out to a folder on disk (adding (2), (3) if a filename already exists there).

In a Team Lab: inspecting files outside a notebook with ELNFileViewer.exe

The Commercial build includes a standalone personal viewer program, ELNFileViewer.exe (marked by a red notebook icon). It loads the same folder browser and all 26 viewer plugins without asking for a login or connecting to MySQL or WebDAV. Press Ctrl+O, drop a single file onto the window, or pass a file path on the command line (ELNFileViewer.exe "C:\Measurements\sample.mit"). You can inspect .mit, .fibps, .zrw, .xrcx, .vk4, or .depo.json files on an instrument PC before you attach them to a notebook.
