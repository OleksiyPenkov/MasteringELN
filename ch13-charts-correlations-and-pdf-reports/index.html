Part 3 · Chapter 13

Experiment Series, Charts, and PDF Reports

In This Chapter

  • Planning and tracking a multi-point Experiment Series (Project > Series...)
  • Making or linking depositions, confirming planned values, and exporting to OriginLab
  • Plotting experimental Conditions against test Results with Tools > Analysis...
  • Generating formatted A4 or Letter PDF experiment reports and JSON scientific packages

Because APS ELN separates Conditions (EXP_CONDITION) from Results (TEST_RESULT) when you extract values (Chapter 9: Conditions, Results, units, and plausible-range checks), you don’t need to copy numbers from ten depositions into a spreadsheet by hand. You can plan and track a structured Experiment Series (Project > Series…), plot any deposition condition against any test result in Tools > Analysis…, or print a formatted PDF report of your experiment tree (Figure 13-1).

Planning and running an Experiment Series

An Experiment Series is a structured plan for a set of depositions or runs that you want to compare, such as sputtering at 100 W100\,\text{W}100W, 200 W200\,\text{W}200W, and 300 W300\,\text{W}300W. It gives you one table and one plot across all points in the sweep.

To create a new series in the Desktop GUI:

  1. Select a project in the left Projects panel and choose Project > Series… (or click Series on the Projects toolbar).
  2. Click New series….
  3. Enter the Title and Purpose - what this series tests, and pick the Target folder where its depositions will be created.
  4. Under Factors, click Add… to choose one or two parameters that you vary. Select the Category and Value type, enter an optional Label (such as Mo layer to distinguish which layer a Time or Power factor applies to), and set optional range limits.
  5. With one factor, enter the semicolon-separated Levels (for example, 100; 200; 300). With two factors, enter the levels for each factor and click Fill grid to generate every combination as a plan point.
  6. Under Fixed conditions, click Add… for each parameter held constant across the series (entering its value and optional tolerance). Under Responses, click Add… for each result value type you will measure on every point.
  7. Click OK.

A series created in the Desktop GUI starts as Active right away. (A series drafted by an AI agent via create_series in Chapter 18 starts as Draft until you click Start in the GUI.) While a series has points, you can edit factor labels, fixed conditions, and responses with Edit plan…, or click Add point… to append a new level (marked added in the Point column).

Each plan point appears as a row on the Table tab (Table 13-1):

  • Making a new deposition from a planned row: Double-click a planned row (or right-click it and choose Make deposition…). APS ELN opens the new procedure dialog pre-filled with the series title, the point’s factor levels, item type Synthesis, and the action type and equipment of the previous deposition in the series. When you click OK, ELN creates the procedure in the target folder and writes each factor level and fixed condition onto it with source kind Planned (shown in grey italic as planned).
  • Linking existing depositions: Right-click a planned row and choose Link existing deposition… to pick a top-level procedure you already recorded. You can also select one or more top-level procedures in the center Items panel, right-click, and choose Link to plan point…. ELN matches each procedure to the first free point whose factor values match within tolerance (or tick Add new points for depositions that match no point to add new points inside the factor range).
  • Confirming planned values: While a condition carries the grey italic planned mark, it is a target from the plan rather than a confirmed measurement. The Plot tab and CSV export ignore planned values, and Add > Derived Value… refuses them as formula inputs. Once your deposition runs as planned, right-click its row in the series table (or use the Item menu) and choose Confirm planned values. If the actual setpoint differed, edit the value on the procedure; if a stored factor or fixed condition differs from the plan beyond tolerance, the cell shows a warning icon (Differs from the plan).
  • Handling failed runs: If a deposition attempt fails (for example, a target arcs or a substrate breaks), right-click the row and choose Mark failed… with a reason. The point returns to planned so you can run Make deposition… for the next attempt, while Show failed keeps the failed attempt visible in the table.

Warning: confirm planned values before plotting or exporting a series

A grey italic planned value is never plotted on the Plot tab and is exported as an empty cell by Copy table and Save CSV…. Always right-click the row and choose Confirm planned values (or extract the real condition from your .depo.json file) once the deposition finishes.

Plotting conditions against results

To plot how an experimental input affects a measured property across a project or folder:

  1. Select the project or specimen folder in the Projects panel on the left (for example, Tribology or its BN-DLC Series folder).
  2. Choose Tools > Analysis….
  3. Under X Axis, select the Condition value type you varied across runs (such as Power, Bias, Pressure, or Normal force).
  4. Under Y Axis, select the Result value type you measured on the samples (such as Hardness, Modulus, COF, Wear rate, or Period).
  5. Tick the procedures you want to include in the list (use All or None to toggle the whole list), then click Plot.
  6. Click Copy Data (CSV) to copy the paired (X,Y)(X, Y)(X,Y) data rows to the clipboard for OriginLab or Python, or click Copy Chart to copy the chart image.

To read the plot accurately, you need to know how Tools > Analysis… pairs XXX and YYY for each point:

  • One point per selected Procedure: each point on the scatter plot represents one root Procedure (Proc).
  • How XXX is chosen: XXX is the first matching Condition recorded directly on that Procedure (such as Parameters.Bias =8 V= 8\,\text{V}=8V on Deposition 261015A).
  • How YYY is calculated: YYY is the arithmetic mean of all matching Result values across three levels under the procedure. It includes direct child actions of the procedure, actions directly below child Specimens (such as Thickness 261015A, Indentation 261015A, and Friction test 261015A), and one further action level below those specimen actions (such as Wear track 261015A or XRR fit 261014B).
  • Any procedure that lacks either the selected XXX condition or at least one matching YYY result within those levels is omitted from the plot.

Remember

Tools > Analysis… reads the Condition from the root Procedure and the Result from its child actions (down to two levels below a Specimen). Always store deposition and synthesis inputs on the Procedure and characterization outputs on the child Actions (Chapter 6: Designing a clean item hierarchy).

When enough points are plotted, APS ELN draws a linear regression line automatically. Treat that line as a visual guide rather than a statistical proof: the regression does not weight points by their stored tolerances (STD). Use Copy Data (CSV) when you need weighted fitting or error bars in a publication figure.

Exporting a formatted PDF report

When you need a clean document for a weekly group meeting, a thesis appendix, or a collaborator who does not have your notebook open, generate a PDF report with File > Export Report…:

  1. In the center Items panel, select the Procedure root (Proc, such as Deposition 261015A).
  2. Choose File > Export Report….
  3. Under Items to include, tick the child specimens and actions you want in the report.
  4. Tick the Sections to include: Metadata, Protocols, Values, Files, Tags, Comments, and Signatures. The Values section prints both the numeric values and their stored tolerances.
  5. Choose the page size (A4 or Letter) and click Browse… to set the Output path.
  6. Click Preview to inspect the formatted report in the HTML viewer, then click Export PDF.

Warning: select the Procedure root before opening Export Report

If you select a Specimen or a single Action in the item tree before choosing File > Export Report…, the Items to include checklist offers only that single row without its children. Always select the top-level Procedure (Proc) when you want a complete multi-action experiment report.

Exporting and importing scientific packages

APS ELN can also export and import structured JSON scientific packages (File > Export... and File > Import scientific package...):

  1. To export, select a project and folder, choose File > Export…, and tick the Items to export. Set the Export path, choose whether to include file metadata (Include files) and protocol status history (Include status history), and click Export.
  2. To import a package into another notebook, select the destination project and folder, choose File > Import scientific package…, browse to the JSON file, inspect the Package preview, and click Import.

Warning: a scientific package is not a notebook backup

In File > Export…, ticking Include files writes file metadata into the JSON package while omitting the raw .fibps, .mit, .zrw, or .xrcx attachment bytes. Likewise, File > Import scientific package… restores only top-level item metadata and protocol forms or templates (always starting imported protocols as Draft). Never rely on a scientific package or a PDF report as a backup of your laboratory data.
