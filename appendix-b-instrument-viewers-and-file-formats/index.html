Instrument Viewers and File Formats

In This Chapter

  • All 26 built-in viewer plugins and their registered file extensions
  • Data file reader IDs, versions, and extracted key names
  • Shared viewer selection modes for FIBPS, MIT, and ZRW

APS ELN ships with 26 built-in Content Viewer plugins (Chapter 7: How file attachment and extension routing work). When a file is selected in the Items panel (or opened in the standalone ELNFileViewer.exe), the host selects the viewer matching the longest registered extension of the filename. Viewers that implement a data file reader (DFR) also extract structured numeric conditions and results via Extract Values (extract_file_key_values in MCP).

Extracted keys and shared viewer selections

Three instrument readers (aps.fibps, aps.mit, and aps.zrw) depend on an evaluation selection saved in the notebook. That selection is recorded in each extracted value’s analysis_snapshot (Chapter 7: Table 7-1 and Chapter 18):

  • FIBPS (aps.fibps v3): When the Step Height tool is active or shared step rectangles exist on the file, extraction emits Step Height and Step Height STD. Its snapshot mode is regions (storing rect_a, rect_b, pix_w, and pix_h) or automatic. Otherwise, if a wear groove is detected, it emits Wear Area and Wear Area STD.
  • MIT (aps.mit v2/v3): Averages Hardness, Modulus, and Reduced Modulus over the indents ticked in Records: and records the selected indent list in the value’s source snapshot.
  • ZRW (aps.zrw v2): Computes COF and COF STD over the cycle interval saved by clicking Apply (or the Automatic plateau if no manual interval was applied). It stores the interval bounds and file hash in analysis_snapshot.
