Toolbar, Menu, and Tree Icons Reference

In This Chapter

  • Icons and row buttons in the Projects and Items panels
  • Scientific item-type icons and tree status badges
  • Main menu and administration icons

This appendix lists the toolbar controls, item-type icons, tree row buttons, status badges, and menu icons displayed in the APS ELN Desktop window (Chapter 3: The three-panel workspace). Both light-theme and dark-theme variants are supplied in the runtime icon assets.

Projects and Items panel toolbars

Table A-1 lists the toolbar buttons at the top of the Projects panel (left) and the Items panel (center).

Table A-1: Toolbar buttons in the Projects and Items panels.

PanelButton nameFunction and menu equivalent
ProjectsNew Project / Add FolderCreates a new project (Project > New Project) or a folder inside the selected project (New Folder).
ProjectsNew Topic WikiSeeds the five-section Wiki/ folder hierarchy inside the selected project (Project > New Wiki).
ProjectsHypothesesOpens the Hypothesis Tree view for the selected project (Project > Hypotheses).
ProjectsMove UpMoves the selected folder one level higher toward the project root (Move Folder Up).
ProjectsShow ArchivedToggles display of archived projects in the tree (Ctrl+Shift+A in the Team client).
ItemsNewOpens creation choices (Procedure, Specimen, Action, or Wiki) for the current selection.
ItemsEditOpens the property editor for the selected item (Item > Edit, F2 in the Team client).
ItemsDeleteMoves the selected item tree to the Recycle Bin, or permanently deletes a selected file or note (Item > Delete).
ItemsAdd FileOpens the file browser to attach one or more files (Item > Add File).
ItemsAdd NoteCreates a rich-text note entry on the selected item (Item > Add Note).
ItemsAdd ProtocolAttaches a structured protocol form from a template (Item > Add Protocol).
ItemsAdd ValueOpens the value entry dialog on a procedure or action (Item > Add Value).
ItemsDuplicateDuplicates the selected item into a chosen project or folder (Item > Duplicate).
ItemsExportExports the selected item tree as a JSON scientific package (File > Export...).
ItemsRefreshReloads the item tree from the database (F5 in the Team client).
ItemsExpand / CollapseExpands or collapses all branches of the current item tree.

Item type icons in the tree

Every row in the Projects and Items panels carries a color-coded icon that identifies its container or scientific item type (Table A-2).

Table A-2: Container and item-type icons in the project and item trees.

Icon nameHierarchy levelScientific role in the notebook
ProjectProject containerTop-level container for a research topic, grant, or material system (Chapter 5).
FolderFolder containerSubfolder organizing procedures and specimens inside a project.
SynthesisProc or ActionMaterial synthesis or thin-film deposition run (such as Deposition 261015A or Deposition 261014B).
TreatmentProc or ActionPre-treatment or post-processing step (such as plasma cleaning Cleaning 261014B or annealing).
SpecimenItem (Specimen)Physical sample, coated coupon, or substrate piece produced or studied in a procedure.
ModelItem (Specimen)Reference structure or computational model under investigation.
CharacterizationActionStructural, optical, or surface characterization step (such as Thickness 261015A or Wear track 261015A).
MeasurementActionQuantitative physical measurement (such as XRR-1 261014B).
TestingActionMechanical, tribological, or functional test (such as Indentation 261015A or Friction test 261015A).
ComputingActionData fitting, simulation, or numerical modeling step (such as XRR fit 261014B).
WikiItemMarkdown knowledge-base page inside one of the five project Wiki sections (Chapter 11).
ProtocolAttached entryStructured protocol form attached to an item (Chapter 8).
Note / OtherAttached entry or ItemRich-text note entry attached to an item, or an uncategorized general item.

Tree row buttons and status badges

Selecting a row with children in the Projects panel, the Items panel, or the Hypotheses list reveals three action buttons at the right end of that row. They appear alongside any status or tag badges (Table A-3).

Table A-3: Inline row buttons and tree badges.

Button or badgeWhere it appearsMeaning and behavior
Collapse all belowRight edge of selected parent rowCollapses every nested level under the selected row.
Expand all belowRight edge of selected parent rowExpands every nested level under the selected row.
FocusRight edge of selected parent rowTooltip: Focus: collapse everything else. Collapses all other branches and scrolls the selected row into view.
SIGNED badgeBeside item title in Items panelDark-red rounded badge indicating that the item carries a cryptographic electronic signature and is permanently locked (Chapter 14).
HYP badgeBeside project or item titleIndicates hypotheses in a project (solid when a review decision is pending in Team mode) or an item attached as a hypothesis Run (Chapter 10).
Tag badge(s)Beside item title in Items panelColored label(s) assigned via right-click > Tags... (Chapter 11).

Main menu and administration icons

Table A-4 summarizes the navigation, analysis, integrity, and reference-data icons used across the main menu bar (File, Project, Item, Navigate, Reference Data, Tools, and Help).

Table A-4: Navigation, analysis, integrity, and reference-data menu icons.

Menu command / iconMenu locationPurpose
DashboardNavigate > Dashboard (Community) or Edit > Dashboard (Team)Opens the overview of recent items, project counts, and pending protocol/hypothesis reviews.
Search...Navigate > Search... (Community) or Edit > Search... (Team; Ctrl+F)Opens the full-text and semantic (Search by meaning) search dialog (Chapter 12).
Analysis...Tools > Analysis...Plots procedure-level Condition values against child action Result values (Chapter 13).
Unit Converter...Tools > Unit Converter...Converts values between compatible physical units (Chapter 9).
Protocol Review...Tools > Protocol Review... (Ctrl+Shift+R)Opens the queue of protocols in In Review state awaiting approval or rejection (Chapter 8).
Data Completeness...Tools > Data Completeness...Scans a project or folder against active completeness rules (Chapter 14).
Audit Log...Tools > Audit Log...Displays timestamped Create, Update, and Delete events across the notebook (Chapter 14).
Recycle Bin...Tools > Recycle Bin...Restores or permanently deletes binned item subtrees (Chapter 5).
Value Types / File Types / EquipmentReference Data menuManages the scientific dictionaries, plausible ranges, and reader mappings (Chapter 9).
