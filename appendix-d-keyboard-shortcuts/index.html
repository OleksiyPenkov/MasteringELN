Keyboard Shortcuts

In This Chapter

  • Global and navigation shortcuts in Community and Team editions
  • Projects panel and Items panel shortcuts and multi-select keys
  • Markdown Editor, Help window, and ELN File Viewer shortcuts

This appendix lists the keyboard shortcuts supported in APS ELN Community and APS ELN (“For Teams”) (Chapter 3: The Dashboard and keyboard navigation). Shortcuts that operate on a specific panel require that panel to have keyboard focus and are inactive while the cursor is inside a search box or text field.

Global and main window shortcuts

Table D-1 lists the global navigation and window shortcuts. Note where APS ELN Community and the Commercial (“For Teams”) edition assign different actions to Ctrl+D and F5.

Table D-1: Global and main window shortcuts.

ShortcutAction in APS ELN CommunityAction in Team Lab (Commercial)
F1Help > Keyboard Shortcuts...Help > Keyboard Shortcuts...
Ctrl+FNavigate > Search... (notebook search)Full-text / semantic Search across projects
Ctrl+GNavigate > Go to Item... (by ID or eln:// URL)Go to item by ID or eln:// URL
Ctrl+DNavigate > DashboardDuplicates the selected item when the Items panel has focus (use Edit > Dashboard for the Dashboard)
F5Not bound (use Refresh in the menu or toolbar)Refreshes the active panel
Ctrl+EUse File > Export... from the menuFile > Export Package
Ctrl+Shift+AUse Show Archived in the Projects panelToggles archived projects visibility
Ctrl+Shift+CNot boundCopies the selected file path
Ctrl+Shift+RUse Tools > Protocol Review... from the menuOpens the Protocol Review Queue

Projects panel and Items panel shortcuts

Table D-2 lists the keyboard and mouse-modifier bindings for the Projects panel and the Items panel (Chapter 5 and Chapter 6).

Table D-2: Projects panel, Items panel, and multi-selection shortcuts.

ShortcutRequired focus / scopeAction
Ctrl+Up / Ctrl+DownFocused root item in Items panel (both editions)Moves the selected top-level root procedure up or down in manual order.
Ctrl+clickItems panel (both editions)Adds or removes the clicked row from the current multi-row selection.
Shift+clickItems panel (both editions)Selects the contiguous range of rows from the focused row to the clicked row.
Shift+Up / Shift+DownItems panel (both editions)Extends the multi-row selection up or down by one row.
InsProjects or Items panel (Team edition)Creates a new project (in Projects panel) or a new item/action (in Items panel).
F2Projects or Items panel (Team edition)Opens the Edit dialog for the selected project, folder, or single item.
DelProjects or Items panel (Team edition)Deletes the selected empty folder, or deletes all selected items/files/notes.
Ctrl+Shift+DProjects panel (Team edition)Creates a New Folder inside the selected project or folder.
Ctrl+NItems panel (Team edition)Creates a new item.
Ctrl+Shift+FItems panel (Team edition)Attaches a file (Item > Add File).
Ctrl+Shift+NItems panel (Team edition)Adds a rich-text note (Item > Add Note).
Ctrl+Shift+PItems panel (Team edition)Attaches a protocol (Item > Add Protocol).
Ctrl+Shift+VItems panel (Team edition)Adds a numeric value (Item > Add Value).

Markdown Editor shortcuts

Table D-3 lists the shortcuts active when the Markdown Editor has focus (Chapter 7 and Chapter 11).

Table D-3: Markdown Editor shortcuts (both editions).

ShortcutAction
Ctrl+SSaves the edited Markdown body through the notebook attachment service (prompting on conflict).
Ctrl+BWraps the selected text in Markdown bold markers (**...**).
Ctrl+IWraps the selected text in Markdown italic markers (*...*).
Ctrl+KInserts a Markdown link ([label](url)) using the selected text as the label.
Ctrl+VPastes text normally; if the clipboard holds an image and no text, uploads the image as an item attachment and inserts its Markdown image reference.

Table D-4 lists the shortcuts in the built-in Help viewer window, the FIBPS viewer, and the standalone ELN File Viewer (ELNFileViewer.exe).

Table D-4: Help window, FIBPS viewer, and ELN File Viewer shortcuts.

Window / ViewerShortcutAction
Help window/ or Ctrl+FMoves keyboard focus to the Search Help box.

Help windowAlt+Left / Alt+RightNavigates back or forward between viewed Help pages.
FIBPS viewerShift+click (in Profile tool)Plots a vertical line profile instead of a horizontal line profile.
FIBPS viewerEscCancels the active tool, turns Flatten off, and clears temporary chart regions.
